# Departments (level 1)

Adds to the root rules.

- Each department has `AGENTS.md` (only its own rules), `memory/INDEX.md` with one fact per file, a `mail/` box and projects with `project.json`.
- Department knowledge stays in the department; do not copy it into other departments or into global memory.
- Projects: status file first, then the project's `LESSONS.md`. Dates are real dates from `date`. Progress is written after each step.
- Visual projects go through R10 (variants first). Documents go through a sample chapter and a blind reader.
- Closing a project: `status: closed` and `closed_on`; management updates the statistics.
- Estimate before each assignment and record actuals afterwards.
