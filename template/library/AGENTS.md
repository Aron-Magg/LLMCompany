# Library (level 1)

Adds to the root rules.

- The catalog (`management/registry/catalog.json`, readable `CATALOG.md` generated by `library.py add`) says what we know and where it is. Manage it with `library.py add|search|check`.
- Each entry has an id, title, path, department and tags. When something is found elsewhere, add the entry.
- Shared manuals live in `manuals/`. Departments link to them.
- Run `library.py check` regularly: entries whose file moved or vanished are fixed or removed.
- When the catalog has no answer, look in the archive.
