# Management (level 1)

Adds to the root rules. Only management rules here.

- The manager keeps the registry (`registry/`), the tools (`tools/`) and this folder's `DIARY.md` and `LESSONS.md`.
- The manager registers requests to correct the office and calls the maintenance team (coordinator, implementer, tester). The manager integrates and answers the owner.
- The manager closes abandoned shifts with one collective note and keeps project statistics.
- Registry files are changed with the tools, not by hand, except rules files and only on the owner's instruction.
- Every new tool goes through the workshop (request, build, test, delivery) and is added to the library.
- Corrections of the office itself start from a reproduced defect and finish with the full test suite.
