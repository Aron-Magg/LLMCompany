# Staff (level 1)

Adds to the root rules.

- Presence is recorded by `office.py` in `management/registry/presence.json` (with `moves.jsonl` and `sessions.json`); there is no attendance file in `staff/`.
- `roles/<role>/ROLE_CARD.md` holds the experience of a job. Read it when assigned; update it when leaving.
- If a role does not exist and the owner trains you, create its card from `roles/_example/`.
- `resignations/` holds exit letters written at `/fired`.
- Reserved names for named assignments are not given to other colleagues by chance.
